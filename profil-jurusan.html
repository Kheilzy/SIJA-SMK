Apa itu sija?

​Jurusan Sistem Informatika, Jaringan, dan Aplikasi (SIJA) di SMK Negeri 2 Yogyakarta merupakan program keahlian yang memadukan keterampilan dalam bidang teknik komputer dan jaringan. Program ini bertujuan untuk membekali siswa dengan kompetensi dalam instalasi, perawatan, dan administrasi jaringan komputer, serta pengelolaan sistem operasi dan aplikasi komputer.​

Kopetensi keahlian

  • Infrastruktur komputasi awam
  • Platfrom komputasi awam
  • Internet of things
  • Keamanan jaringan
  • Produksi Kreatif

Materi Pembelajaran Kelas 10

  • Web Programing Belajar tentang HTML, CSS, dan JavaScript untuk membuat halaman web interaktif.
  • Jaringan Dasar Memahami konsep dasar jaringan komputer, termasuk topologi, protokol, dan perangkat jaringan.
  • Hardware Memahami komponen komputer, cara merakit, dan melakukan perawatan perangkat keras.

Materi Pembelajaran Kelas 11

  • Internet of Things (IoT) Memahami konsep dan aplikasi IoT, serta cara menghubungkan perangkat ke internet.
  • Cloud Computing Memahami konsep komputasi awan dan cara menggunakan layanan cloud untuk penyimpanan dan pemrosesan data.
  • Mobile Programming Belajar tentang pengembangan aplikasi mobile menggunakan platform Android.

Materi Pembelajaran Kelas 12 dan 13

  • Internet of Things (IoT) Lanjutan Memahami konsep lanjutan IoT, termasuk sensor, aktuator, dan komunikasi antar perangkat.
  • Cloud Computing Lanjutan Memahami layanan cloud lanjutan, termasuk penyimpanan, analisis data, dan keamanan data.
  • Keamanan Jaringan Memahami teknik dan alat untuk melindungi jaringan dari ancaman dan serangan.
  • Insfrastruktur as a Service (IaaS) Memahami konsep IaaS dan cara mengelola infrastruktur TI menggunakan layanan cloud.

Fasilitas

Di gedung sija menyediakan berbagai lab yang digunakan sebagai media pembelajaran dengan fasilitas yang menadal. Mulai dari device komputernya, Ruang praktik mekanik elektro, Ruang praktik instalasi jaringan dan 3 Ruang praktik pengembang aplikasi serta terdapat ruang server yang digunakan untuk menyimpan server dan beberapa alat lainnya.
